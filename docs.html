If something goes sideways

TROUBLESHOOTING

Arsenal says the package is not active.

Confirm that you imported the packaged release ZIP, enabled the project, and deployed your configuration. When updating FAA, disable the previous package so only one version is active.

A game update changed mod behavior.

Check the project's release notes for compatibility. FAA uses an exact-build check, and Expanded Tips may need a localization update. Use a supported release.

I want to remove a mod.

Disable or remove it in Arsenal and redeploy. For runtime mods such as FAA, restart the game after changing the deployed configuration.

Where should I report a problem?

Use the project's Nexus posts or linked repository. Include the mod version, game build, steps to reproduce, and other installed mods. For FAA, include the weapon and selected profile.
