The approved P5 directional palette is included in SRAF 1.0.0 SDC Edition. Preview the four chimes and example stratagem sequences before downloading.

Each directional input triggers one compact, continuous 110 ms chime. The palette uses newly synthesized sounds without extracted game audio, voice lines, or melodies.

Every audio sample is embedded in this page. The native player controls work in the browser; no extra files or downloads are needed.
